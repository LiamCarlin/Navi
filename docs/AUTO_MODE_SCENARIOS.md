# Auto-mode test scenarios

400 tasks for Navi in **auto mode** (Jev-first driver, approvals only for irreversible actions), from one-step to long cross-app chains. Each row: what the user says, the screen it is said over, and the **correct ending** — the typed verdict (only `achieved` counts as completed), whether auto mode must stop once for an approval, and the end state.

Generated from `scripts/taskbench/scenarios/rows_*.py` by `python3 scripts/taskbench/scenarios/build.py`, which also writes `scripts/taskbench/scenarios.json` (tasks.json schema + `tier`, `ending`) — run it through the offline bench with `NAVI_BENCH_TASKS=scripts/taskbench/scenarios.json`. Edit the rows, not the outputs.

**Tiers:** 1 one action · 2 a few steps on one surface · 3 multi-step with data entry or judgement · 4 cross-app or grounded in the user's own memory · 5 long chains.  
**Approval:** auto mode asks exactly once, right before that step; the ending assumes the user approves.  
**Purchases** end in the cart ("Ready for you to place the order") — Navi never pays.
