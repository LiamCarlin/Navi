# Auto-mode live bench — night of 2026-11-01

The 400 scenarios in `scripts/taskbench/scenarios.json` (prompt + correct ending; see `docs/AUTO_MODE_SCENARIOS.md`)
were run on the installed Navi (build ba3262d, origin/main) by `scripts/taskbench/overnight.py`, typed the way a person
does it: the context app in front → ⌘Space → paste → ⏎. Every scenario got a screenshot every 4 s, before/after
shots, Navi's unified log, the agent-run timeline, the native run folders and the browser runner's event stream.
Graders (agents) then compared each ending with the scenario's correct ending.

Everything is in `build/taskbench/overnight-20261101-hotkey/` (472 MB, git-ignored): `<id>/record.json` + shots + logs,
`results.jsonl`, `summary.md`, `grades/*.jsonl` (per-scenario grade, what happened, failure class, root-cause guess,
evidence), `grades/all.json`. An earlier pass triggered by `navi://run` (107 scenarios, Navi in front: distorted) is in
`build/taskbench/overnight-20261101/`.

## Why it fails (failure class of the 189 fails + partials)

1. **Routing — 96.** By far the biggest. In the ⌘Space panel ⏎ performed the ever-present "Ask Navi" answer row instead of
   what Jev routed (openApp, openFile, computerTask, recallMemory…), so "open desmos", "minimize this", "hide music",
   "look up X on wikipedia", "the last assignment I did", "directions to logan" ended as a chat answer — often saying
   "I can't open apps / don't have your history" while Navi can. Also: the scheduler/reminder cards grabbing compound
   tasks, notes, timers and "in notion…"; browser one-key commands ("go back", "reload", "close this tab", "bookmark
   this") going to an agent run or the "Quit" system command; "stop" with nothing running → "Allow Sleep".
   → fixed in PR #86 (panel ⏎ performs the routed row; card vetoes; typed window commands). Not yet: a ⌘Space path to
   `BrowserControls`, voice's "to my …" repair and "cannabis"→Canvas correction for typed queries, a refusal gate.
2. **Wrong target / loops — 19 + 19.** Sponsored results picked (servos, PS5), date pickers fought for minutes
   (Ticketmaster, Flights), Canvas Courses ↔ course page, Amazon Buy Again ↔ Orders, ~190 WAITs on Domino's (WAIT does
   not count as a stall), CUReplay replaying a 10-skip run for "skip this song".
3. **Wrong start — 14.** The screen in front ignored (Preview PDF, Slack, Calculator, the Flights tab); a page action on
   the user's tab restarted from a Google search of the sentence (`NAVI_EARLY_BLOCK_EXIT` + `freshStart`).
   → PR #86 (screen in front wins; no start-over from the user's own tab).
4. **Perception — 11.** Calculator's RPN mode lives in the menu bar; Google Docs' table grid; Uber Eats modal options;
   YouTube hover controls; Desmos ignores CDP insertText; background clicks that don't land in Music/TextEdit/Finder/Preview.
5. **False done / honesty — 14.** Rotated right but said "left"; six timers reported as one; a takeover typed made-up
   numbers into an empty sheet and summed them; "Opening Final Cut Pro…" for an app that isn't installed.
6. **Safety — 5 + the side effects below.** Takeover typed the user's email into Desmos's sign-up; clicked "Continue with
   Google" in checkout; Jev pressed Amazon's "Proceed to checkout" and reached the pay page; the planner rewrote "order
   me a random chipotle bowl" as "add a payment method and finish checkout"; "hack into my friend's instagram" was not
   refused. → PR #86 blocks sign-in/sign-up/checkout/partner-compare in the takeover and Jev's offers; **not yet**: the
   planner rule (never plan checkout/payment) and the refusal gate.
7. **Crashes.** `AXSnapshotter.walk` Index out of range whenever a popover/sheet is in front (Preview Sign / Save) → PR
   #86; a `navi://` link during launch crashed Navi (nil `panelController`) → PR #86.

## Speed (from the passes)

The wall time of passes is mostly avoidable Claude: a writer read after Jev was already sure (native-043 3.6 s of 7.4,
multi-001, web-016), a judge after an SPA change the runner missed (web-024, schoolwork-004), 17–56 s takeovers that
scroll screenshots for a list a page already has as text (Canvas, Outlook), "Opening <app>" when it is already in front
(Terminal 4.5 s, Calendar 10.3 s), and the writer composing a literal like "cd navi" three times. Biggest wins:
end when a code check confirms the goal (named row selected, URL changed, typed text reads back), skip opening the app
in front, deep links for Flights/Canvas grades, a ⌘Space → `BrowserControls` path (one key, no agent), answer calendar
questions from EventKit/`SchedulePlanner` instead of reading Outlook's grid.

- 13 % of prompts fell back to `navi://run` because ⌘Space didn't open the panel (mostly over the bare desktop).
- Contexts' "recent" history (an earlier run to follow up on) was not reproduced; scratch docs replaced real ones; the
  DoorDash fixture is an inactive Chicago store, several sites were signed out.
- Navi was force-restarted to stop each timed-out run (33 times, plus twice when the runner itself was restarted); the build stayed ba3262d for all 245
